# 验收与测试矩阵

状态：待实现测试清单，不表示当前已通过。优先对数据约束、恢复和协议边界写有意义的测试，不为每个纯包装函数逐行镜像测试。

## 测试组织

- Python：pytest，临时 SQLite、假抓取器、假 HTTP server、假 Mihomo controller、可注入时钟。
- TypeScript：协议解析和组件关键交互；用 Playwright Electron 做少量端到端主路径。
- 合成 fixture 与源码一同提交；不得使用私人结果、简历、节点或 Key。
- 默认测试禁用真实网络。真实 LinkedIn/Indeed、模型、Mihomo 验证作为独立显式步骤，记录时间、版本和结果。
- 所有故障测试用超时避免挂住。功能测试通过后再做小范围真实验证，不重复抓取来验证 UI。

## JobSpy 升级契约

以下使用 ARCHITECTURE 固定提交的输出形状和本地模拟响应；不通过扩大真实抓取量验证。

| ID | 场景 | 验收断言 |
| --- | --- | --- |
| J01 | LinkedIn/Indeed 调用参数 | 每 task 仅一个显式平台，offset=0；LinkedIn 使用 fetch_description=True，不传已弃用参数或不支持的筛选；不自动启用其他平台 |
| J02 | 空表、有错误空表、有错误部分结果 | 正确区分成功零结果、失败和可用部分结果；读取并独立传递 attrs，转换后诊断不丢失 |
| J03 | warnings、详情缺失、调用抛异常 | 警告不自动判失败；缺 JD 单独计数并走既定规则；异常被捕获，不把错误当零结果 |
| J04 | 参数错误、429、任务重试 | 参数 ValueError/TypeError 不重试；网络失败有限退避；不依赖旧内部自动重试，已提交成功任务不重抓 |
| J05 | 列顺序变化、空表、NaN/NaT/pd.NA、合法 0 | 按列名映射、缺失值正确转换，0 保留；不把 nan 写成正文或唯一身份 |
| J06 | LinkedIn 无外部直链、其他来源有直链 | 平台页面可打开；缺失直链不造身份，后续来源可补充；既定去重规则不变 |
| J07 | 日志和 HTTP 观测 | 标准 logging 接入工作进程 stderr，诊断脱敏；实际 429 可观测，观测不污染 LLM 请求 |
| J08 | 新版地点/JD/日期/薪资输出 | 合成字段样例经过映射、归一化、筛除及导出回归，保持空值和原薪资单位；不因上游列变化修改业务去重规则 |

### 自动评分开关

- 默认开启；关闭后新岗位正常入库为 unscored，无评分任务/评分请求，运行可正常结束，评分计数为 0。
- 修改开关仅影响新运行，续跑使用原快照；已有分数不变，历史 unscored 不自动补评。
- 关闭期间仍可在 Jobs 或 Shortlist 对未评分岗位手动评分；失败不能记作 0 分，已有成功分数仍保留。

## 运行、代理和计划

| ID | 场景 | 验收断言 |
| --- | --- | --- |
| R01 | 同时 start、计划触发、启动响应超时 | 只有一个运行；前端禁用重复点击，确认超时先查状态、不自动重发；运行中到点的计划记 waiting，结束后自动开始 |
| R02 | 正常零结果与访问失败 | 前者可成功，后者明确失败/部分完成 |
| R03 | 一任务重试多次结果重叠 | 多次尝试合并交给统一去重模块，重复返回行不重复计入筛除统计；提交可用记录；失败重跑替换任务统计，本轮唯一数按 run_jobs 汇总；已提交成功任务不重抓 |
| R04 | 评分中停止，完成若干结果后续跑 | 停止派发/重试，等待已发出 LLM 请求结束，成功结果保存；stopping 期间拒绝新运行，未完成续跑重新排队，0 分仍是成功 |
| R05 | 工作进程/service/Electron 异常退出 | 重启状态无永久 running，恢复不依赖内存；子进程可控 |
| R06 | 每批入库事务提交前后崩溃 | 提交前无半批岗位/完成标记，恢复整任务重抓；提交后岗位/评分任务/统计/完成标记齐全，跳过成功抓取；不依赖 raw/manifest |
| R07 | 用户改设置后 resume | 业务快照不变，允许修正 Key，不读取私人 .env |
| R08 | 显式 resume 已耗尽尝试任务 | 获得新有限尝试次数，成功任务不重做，无无限自动循环 |
| R09 | 抓取/评分运行期间浏览和改备注 | UI 可响应，未持有长写事务；清理 BUSY |
| R10 | A 抓取完成、B 仍在抓取 | A 结果立即可见并评分；遵守全局 RPM/并发，不等待 B；分别展示进度 |
| R11 | 后续批次命中已在评分的岗位 | 同轮跨平台规则跨批生效，补全来源/方向/身份，不替换正文、不重复派发评分 |
| R12 | 抓取结束而评分仍在处理 | run 不提前完成；停止同时停止两类派发，恢复可先评已入库岗位 |
| R13 | 入库后派发前崩溃；跨批相同评分输入 | 待评分任务不丢失，同一 job 不重复登记，不同 job 各自评分；已成功分数不重算 |
| R14 | 旧岗位重评停止/中断后被自动清理，较新运行仍存在 | 续跑将缺失岗位任务标 failed/NOT_FOUND，零模型调用且不增加尝试数；继续存活岗位，不恢复已删岗位；全部缺失或混合情形均结束，Ping 仍响应 |
| R15 | worker 的请求开始通知被满队列阻塞期间取消 | 队列释放后不调用 transport，任务以 cancelled 结算，最终尝试次数不包含未发送请求；已发请求仍保存成功结果 |
| R16 | 只选部分搜索运行；所选方向之后被删除 | 只生成所选方向启用 query 的任务，快照与历史显示所选搜索；去重、批次跨运行全局生效；删除方向后计划移除该 ID，无剩余时自动关闭，runs.start 剩余为空返回 VALIDATION_ERROR |
| P01 | 高级模式代理关闭 | 深度、并发、RPM 可改并可运行 |
| P02 | 普通代理/代理池端口冲突或配置错误 | 明确失败，不修改其他服务，不静默直连 |
| P03 | 重复出口、冷却、候选失败 | IP 去重和冷却生效，失败恢复原节点 |
| P04 | 429 压力、轮换失败、端口停用 | 退避和归还队列符合策略，不无限重试 |
| P05 | 在途请求未结束时到达换批条件 | 等端口任务耗尽再切，不影响其他端口 |
| P06 | provider-only 配置、退出和中断 | 不支持格式明确提示；只清理本 App 实例和临时配置 |
| S01 | 多天休眠或 App 退出后唤醒/重新打开 | 不自动运行；每个开启计划只记最近一条 not_run（含累计错过次数），可手动 Run now 或删除，删除无运行数据残留 |
| S02 | DST 跳时/重复时、系统时区变化 | 使用计划 IANA 时区，重复时不触发两次 |
